# DeltaLootForge

DeltaLootForge is a Minecraft mod designed to enhance the loot system in Minecraft, specifically for the Delta modpack. It introduces a forge that grants +1 loot to items, compatible with Delta's tower ticket system, providing 100 tickets per execution.

## Install

1. Download the DeltaLootForge mod file.
2. Place the downloaded file in the `mods` folder of your Minecraft instance.
3. Launch Minecraft and ensure the mod is loaded correctly.

## Use

1. Locate the forge in the game world.
2. Interact with the forge to apply the +1 loot enchantment to your items.
3. Use the tower ticket system to execute the forge, granting 100 tickets per execution.
